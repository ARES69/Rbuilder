# RBuilder на macOS — установка, сборка, удаление

## Что вы получаете

**RBuilder Desktop** — нативное macOS-приложение (Tauri 2 + WKWebView).

После сборки появляются готовые артефакты:

- `src-tauri/target/<arch>/release/bundle/macos/RBuilder.app` — приложение;
- `src-tauri/target/<arch>/release/bundle/dmg/RBuilder_0.1.0_<arch>.dmg` —
  дистрибутивный образ;
- `RBuilder_<версия>_macOS_<arch>.dmg` в корне проекта — образ, собранный
  хелпером `make-rbuilder-dmg.command` (удобен для universal-сборки).

Их можно передавать на другие компьютеры — там **не нужны** Rust, Bun и Xcode:
пользователь открывает `.dmg` и перетаскивает RBuilder в Applications.
Поддерживаются Apple Silicon (M1–M4) и Intel; при наличии обоих тулчейнов
скрипт собирает universal-бинарник.

## Способ 1 — простой (рекомендуется): собрать на своём компьютере

Подходит любому macOS 11+ (Big Sur или новее). Нужен интернет и 10–20 минут на
первый запуск (Rust компилируется дольше всего, ставится один раз).

1. Скачайте папку проекта. Предпочтителен **Git clone** — ZIP-архив не
   сохраняет права на исполнение скриптов, и их придётся возвращать вручную
   (см. таблицу ниже).
2. Если качали ZIP: в Терминале перейдите в папку и выполните
   `chmod +x setup-mac.sh *.command`.
3. Двойный клик по **`install-rbuilder-mac.command`** → правый клик →
   **«Открыть»** (или System Settings → Privacy & Security → «Open Anyway»).
   Скрипт сам поставит всё, чего не хватает: Xcode CLT, Bun, Rust,
   зависимости проекта.
3. Когда всё готово — двойный клик по **`build-rbuilder-mac.command`**:
   проверки → веб-сборка → `.app`/`.dmg`.
4. Готовый `.dmg` — в `src-tauri/target/*/release/bundle/dmg/`.

Терминал откроется сам и покажет ход установки; по завершении окно можно
закрыть.

> **Почему нужно «правый клик → Открыть»**: macOS блокирует скрипты, скачанные
> из интернета (Gatekeeper). Разрешение запрашивается один раз, потом файлы
> запускаются двойным кликом как обычно.

## Способ 2 — готовый .dmg из GitHub Releases (без сборки вообще)

Если в репозитории настроен GitHub Actions (файл
`.github/workflows/desktop-build.yml`), universal-сборка для Apple Silicon и
Intel делается автоматически на серверах GitHub:

1. Поставьте тег: `git tag v0.1.0 && git push origin v0.1.0`
   (или запустите workflow вручную: вкладка **Actions** → **Desktop installers** → **Run workflow**).
2. Скачайте `.dmg` во вкладке **Actions** (артефакт `macos-dmg`) или в
   разделе **Releases** (при пуше тега релиз создаётся сам).

На вашем Mac для этого не нужно ничего — ни Xcode CLT, ни Rust, ни Bun.
Подпись: см. раздел «Подпись и Gatekeeper» — непосещённый CI-бинарь
всё равно потребует «правый клик → Открыть» при первом запуске.

> Ссылка на Convex-бэкенд берётся из секрета `VITE_CONVEX_URL` репозитория
> (Settings → Secrets and variables → Actions). Без секрета соберётся
> плейсхолдер — приложение запустится, но не подключится к бэкенду.

## Способ 3 — без сборки: режим разработчика

Если инсталлятор не нужен и достаточно окна приложения на этом компьютере:

1. `install-rbuilder-mac.command` — один раз (ставит окружение).
2. Запуск: `bun tauri dev` (окно приложения) или `bun run dev` (только веб
   в браузере).

## Способ 3 — если ничего не устанавливать на Mac

RBuilder — это веб-приложение: фронт (Vite) + бэкенд (Convex). Его можно
вообще не собирать в десктоп:

1. Развернуть фронт на бесплатном хостинге Vite-сборки (Cloudflare Pages /
   Netlify / Vercel) и указать `VITE_CONVEX_URL` на ваш Convex deployment.
2. Открыть ссылку в Safari/Chrome — тот же интерфейс без установки.
3. macOS-версия имеет смысл, когда нужен локальный workspace агента (файлы на
   диске, Git) и приватный режим (LM Studio/Ollama на своём железе).

## Universal-сборка (Apple Silicon + Intel одним файлом)

Скрипт делает это автоматически, если установлены оба тулчейна:

```bash
rustup target add aarch64-apple-darwin x86_64-apple-darwin
```

После этого `build-rbuilder-mac.command` соберёт `universal-apple-darwin`, и
один `.dmg` будет работать на обоих типах Mac. Без второго тулчейна сборка
идёт под архитектуру текущей машины — тоже рабочий вариант.

## Подпись и Gatekeeper (для распространения)

Неподписанный `.dmg` при первом открытии на чужом Mac вызывает предупреждение
«не удалось проверить разработчика». Варианты:

- **Без аккаунта Apple Developer (бесплатно):** получатель нажимает правой
  кнопкой → «Открыть» → «Открыть» в диалоге, либо System Settings →
  Privacy & Security → «Open Anyway». Приложение запускается.
- **С аккаунтом Apple Developer ($99/год):** добавьте в
  `src-tauri/tauri.conf.json` секцию `"bundle" → "macOS"` с
  `signingIdentity` (например, `"Developer ID Application: ..."`), и соберите
  на Mac с этим сертификатом в связке ключей. Затем `codesign` + `notarytool`
  по документации Tauri: <https://tauri.app/distribute/sign/macos/>

Для внутреннего использования (свой компьютер, команда) подпись не нужна.

## Удаление

- Двойный клик по **`remove-rbuilder-mac.command`**: остановит приложение,
  уберёт артефакты сборки, установленный `.app` и настройки — каждый шаг с
  подтверждением; Rust и Bun удаляются только по явному «y» (их могут
  использовать другие проекты).
- Точечно: `rustup self uninstall`, `rm -rf ~/.bun`,
  перетащить `RBuilder.app` в Корзину.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| «Файл нельзя открыть, так как не удалось проверить разработчика» | Правый клик по `.command` → «Открыть» → «Открыть». Или System Settings → Privacy & Security → «Open Anyway» |
| Терминал пишет `Permission denied` | Файл не получил право на запуск после распаковки ZIP: в Терминале `chmod +x *.command setup-mac.sh` |
| Установка CLT не начинается | Откройте Терминал и выполните `xcode-select --install`, подтвердите диалог, затем перезапустите скрипт |
| `error: unable to find utility "git"` | Xcode CLT доустановились не полностью. Перезапустите `install-rbuilder-mac.command` — он продолжит с места ошибки |
| Ошибки `Cannot find module '@/convex/_generated/api'` и сотни ошибок типа `TS7006` | В скачанном архиве нет папки `src/convex/_generated` (генерируется автоматически). Скрипт сам её создаст при первом запуске; либо вручную: `bunx convex codegen --typecheck=disable` |
| Сборка падает на `bun install` | Проверьте доступ к npm-реестру (корпоративный прокси?). Выполните `bun install` вручную, затем `build-rbuilder-mac.command` |
| `linker "cc" not found` | Не установлены Xcode CLT. Перезапустите `install-rbuilder-mac.command` |
| Окно приложения пустое | Нет `VITE_CONVEX_URL` — впишите адрес Convex deployment в `.env` и пересоберите |
| `.dmg` «повреждён» на другом Mac | Это Gatekeeper о неподписанном образе — см. раздел «Подпись и Gatekeeper» выше |

Каждый шаг скрипта печатает, что делает; при ошибке выводится
человекочитаемое сообщение и код выхода ≠ 0, так что скрипт можно
перезапускать: он доустанавливает только то, чего не хватает.
